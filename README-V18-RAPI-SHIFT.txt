Perbaikan yang dilakukan:
- Daftar rak dijadikan panel buka/tutup (jumlah rak terlihat).
- Saat dibuka, rak bisa digulir maksimum 290px tanpa menimpa formulir.
- Efek Folder 3D hanya untuk kartu utama, bukan daftar dan formulir di dalamnya.
- Jarak panel, padding, kolom di HP dan tombol diperbaiki.
- Tidak mengubah Supabase, PIC, checklist, foto, jadwal dan akun.

CARA UPLOAD PATCH:
1. Ekstrak ZIP.
2. Upload app.js, themes.css, index.html dan sw.js di root repository GitHub.
3. Commit, kemudian refresh PWA (untuk APK, build ulang dan install ulang).
4. Buka menu Shift, lalu tekan 'Lihat ... rak aktif' untuk membuka daftar.
